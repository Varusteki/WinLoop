# 历史归档目录

这里存放**非项目必需**的文件：开发过程中的旧版本备份、一次性方案产物等。
它们不影响构建与运行，只为「以后想回溯当时怎么做的」留个凭据。

> 归档 ≠ 垃圾堆。目录内每份文件都在下面登记了**来源**与**为什么留着**。
> 新增归档时请一并补登。

## xuankongsi-star-source/

**来源**：`tmp/ref/` 中与**八角星图形生成**直接相关的脚本与数据
**内容**：

| 文件 | 说明 |
|---|---|
| `gen_pathdata.py` | 生成 `CSHeadshotPathData.cs`（墨迹/轮廓回路数据），源图 `r2.jpg`，DP 容差 1.2px |
| `zf1_export.py` | 生成 `CSHeadshotLayers.cs`（图层数据） |
| `r2.jpg` | 矢量化源图 |
| `paths.txt` | 路径导出中间结果 |
| `zz3_model.json` / `zz4_model.json` / `zz8_model.json` | 各阶段的几何模型数据 |

**为什么归档**：`CSHeadshotPathData.cs` 与 `CSHeadshotLayers.cs` 的**文件头注释
明确标注了「生成脚本：tmp/ref/xxx.py」**——它们是这两份源码的**可再生依据**。

当前完整的 `tmp/ref/` 已由 `.gitignore` 排除（`tmp/` 整目录被忽略），
意味着**这份「再生图纸」不会进仓库**。此处保留最小必要集（生成脚本 + 源图 + 模型数据），
确保即使本地 `tmp/` 被清空，也能重新生成八角星图形数据。

**若要重新生成**：需先补回 `tmp/ref/` 的其余辅助脚本（`zz3_*.py`、`zz4_*.py`、
`zz8_*.py` 等），这些脚本间存在互相调用关系。或直接以本目录的模型 JSON 为输入。

**可安全删除**：**否**。删掉后八角星图形将失去可追溯的生成来源。
